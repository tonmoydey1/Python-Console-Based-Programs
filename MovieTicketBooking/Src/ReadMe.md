🎬 Movie Ticket Booking System
📌 Project Description (Descriptive Question)

Objective:
To develop a simple console-based Movie Ticket Booking System using Python and MySQL that allows users to manage movies and book tickets easily.

Description:
The system stores movie details such as movie name, show time, ticket price, and available seats. Users can view available movies, book tickets by selecting a movie and number of seats, and generate a bill based on the ticket price. After booking, the system automatically reduces the available seats. All booking details are stored in the database for future reference without using complex SQL JOIN operations.

Functionalities:

Add new movies with show time, ticket price, and available seats

View all available movies

Book tickets for a selected movie

Automatically reduce available seats after booking

Generate bill for booked tickets

View all booking records
